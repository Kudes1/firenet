# Sidebar Legacy Cleanup — Design

Дата: 2026-09-08. Статус: утверждён (в чате, см. ответы на уточняющие вопросы ниже).

## Контекст

Ревью левого бокового меню React-фронтенда выявило: сам `Sidebar.tsx` не
содержит легаси-логики, но несёт легаси-*паттерны* (ручная подсветка
`active` вместо NavLink, localStorage-ключи с комментариями «1:1 с
common.js»), а вокруг него в `styles.css` остался мёртвый CSS от
легаси-разметки (Alpine.js, бренд, иконки в пунктах меню).

## Решения (утверждены пользователем)

| Вопрос | Решение |
|---|---|
| Скоуп переименования ключей | **Все** `firenet-*` ключи, включая draft- и theme- (с обновлением e2e-хелпера и index.html) |
| Схема имён | `ui.*`: `ui.sidebar`, `ui.nav.<id>`, `ui.theme`, `ui.draft.id`, `ui.draft.lastId`, `ui.draft.readonly` |
| Подсветка активного пункта | **Чистый NavLink** (`end` + `className`-функция), проп `active` из Layout удаляется |
| Бренд в сайдбаре | **Удалить** мёртвые `.brand-*` стили (не восстанавливать) |
| Logout | Оставить `window.location.href = "/login"` (полный сброс состояния) + комментарий «почему не navigate()» |
| Мёртвый CSS | Удалить все 5 находок + актуализировать устаревшие легаси-комментарии |
| user-box | На дизайн-токены (`--space-*`, `--radius-sm`, `--fg`), алиас `--text` удалить |
| Тесты | Юнит-тесты в `Layout.test.tsx` (collapse, тема, logout); без новых e2e-сценариев |

## Механика

- `frontend/src/lib/storage.ts` — единственная точка правды для ключей
  web-storage (`storageKeys`). e2e-хелпер `e2e/helpers/ui.js` пишет
  draft-ключи literal-строками через `addInitScript` — контракт
  фиксируется юнит-тестом `storage.test.ts`.
- Ревизия драфта (`X-Draft-Revision`) живёт в памяти (`api/revision.ts`),
  не в storage — в переименовании не участвует.
- Sidebar: `NavLink` с `end` на каждом пункте; `NavGroup` сам определяет
  активность через `useLocation` (группа раскрыта, если активен любой из
  её путей). Layout сохраняет `activeFromPath` только для выбора
  draft-баннера (`NO_DRAFT_BANNER`), больше не передаёт его в Sidebar.
- A11y: `aria-expanded={!collapsed}` и динамический `aria-label`
  («Свернуть меню»/«Развернуть меню») на кнопке-сворачивании;
  `id="theme-toggle"` удаляется.
- CSS: значения токенов равны прежним hardcoded-величинам
  (`--space-2`=0.5rem=8px, `--space-3`=0.75rem=12px, `--radius-sm`=4px) —
  визуальных изменений нет.

## Вне скоупа

- Восстановление бренда в сайдбаре.
- e2e-сценарии collapse/темы.
- Блок `.submenu`/`.ctx-*` в styles.css — потенциально мёртвый
  (использование в React-коде не найдено), требует отдельного
  расследования (контекстное меню канвы).

## Верификация

После каждой задачи: `cd frontend && npm run typecheck && npm test -- --run`.
Финально: `make test-e2e` (e2e-хелпер меняется), `go build ./... && go vet ./...`
(контроль, что Go-сторона не тронута), остаточный grep на легаси-маркеры.
