# CanvasPanel — плавающие панели канвы (дизайн)

Дата: 2026-09-10

## Проблема

Канвовые модалки редактирования (устройство, сеть, фильтр связи в
TopologyPage) используют общий `components/ui/Modal` на нативном
`<dialog>` + `showModal()`. Это несовместимо с задачами канвы:

- диалог живёт в top layer браузера — его нельзя обрезать рамкой канвы,
  спозиционировать в координатах канвы или якорить к узлам;
- drag-зажим панели работает в координатах окна, панель можно утащить
  за пределы канвы;
- для мир-координат и будущих канвовых фич нужна независимая сущность,
  а не флаг (`undimmed`) поверх модалки табличных страниц.

Решение: разделить. Табличные страницы остаются на `Modal`
(с затемнением), канва получает собственную немодальную плавающую
панель `CanvasPanel`.

## Решение

### Новый компонент `frontend/src/topology/CanvasPanel.tsx`

```tsx
type Props = {
  at?: { x: number; y: number };   // координаты .canvas-wrap
  title: string;
  onClose: () => void;
  children: React.ReactNode;
  wide?: boolean;                  // аналог modal-lg
};
```

- **Рендер**: `position: absolute` внутри `.canvas-wrap` — панель
  рендерится children'ом `TopologyCanvas` (как `ContextMenu`,
  TopologyCanvas.tsx уже так делает для оверлеев). Обрезается рамкой
  канвы, позиция в системе координат канвы.
- **Drag**: за хедер; зажим в rect `.canvas-wrap`. Позиция хранится как
  `left/top`, drag сдвигает их напрямую (без translate-слоя Modal).
- **Позиция**: задаётся `at` один раз при открытии (решено: без живой
  привязки к узлам и без слежения за pan/zoom — легаси-вариант C).
  Дальше панель двигается только перетаскиванием. Без `at` панель
  центрируется в `.canvas-wrap` при открытии (сам измеряет контейнер —
  у страницы нет ref на канву).
- **Esc**: listener на document; не срабатывает, если фокус в
  инпуте/textarea (Esc внутри `Combo` сам закрывает подсказки и должен
  гаситься там). Срабатывание → `onClose()`.
- **Клик вне панели не закрывает**: это форма редактирования,
  случайный клик по канве не должен терять ввод (отличие от ContextMenu).
- **Ловушки фокуса нет**: панель немодальная, канва остаётся
  доступной (Tab уходит с панели — принято).
- Канва при открытой панели интерактивна (нет `showModal`): если
  пользователь удаляет редактируемый узел при открытой форме, панель
  закрывается сама — условный рендер `{editDevice && <CanvasPanel…>}`
  перестаёт выполняться, когда объект исчез из doc.

### Стили

Новый класс `.canvas-panel` в styles.css: хром копируется с
`.floating-panel` (styles.css:524) — фон/рамка/тень/радиус, хедер с
`cursor: move`, тело. `.floating-panel` остаётся для diagnose-панелей
(DiagnosePage) — его не трогаем.

### Изменения в существующем коде

- **TopologyPage.tsx**: три канвовые формы (`DeviceEditForm`,
  `NetworkEditForm`, `LinkFilterForm`) переходят с `Modal` на
  `CanvasPanel`; панель передаётся children'ом `TopologyCanvas`.
  `at` не передаётся — панель центрируется в канве при открытии.
  Состояние `editTarget` остаётся на странице.
- **Modal.tsx**: удаляется флаг `undimmed`; `Modal` остаётся чисто
  табличным (с затемнением `::backdrop`).
- **styles.css**: удаляется правило `dialog.modal.modal-undimmed::backdrop`;
  добавляется `.canvas-panel`.
- **Combo.tsx**: портал подсказок ищет `closest("dialog[open]")`;
  для панелей подсказки должны позиционироваться absolute относительно
  панели — селектор контейнера расширяется на `.canvas-panel`.
- **editForms.tsx**: не меняется — формы переиспользуются как есть.
- **TopologyCanvas.tsx**: не меняется — children уже рендерятся внутри
  `.canvas-wrap`.

## Тесты

- Новый `CanvasPanel.test.tsx`: открытие в точке `at`, drag с зажимом в
  границы канвы, Esc вне инпута закрывает, Esc в инпуте не закрывает,
  клик вне не закрывает.
- `TopologyPage.test.tsx`: проверки `modal-undimmed` (строки ~180/188)
  заменяются на проверки `.canvas-panel`.
- `Modal.test.tsx`: убрать тесты undimmed, если есть.
- Прогон: `npm run typecheck && npm test`, затем `make test-e2e`.

## Не входит (YAGNI)

- Привязка к узлам / мир-координаты, слежение за pan/zoom.
- Ловушка фокуса.
- Трогать diagnose-панели (`.floating-panel`).
